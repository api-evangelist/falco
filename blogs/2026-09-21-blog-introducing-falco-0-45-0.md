Dear Falco Community, we are happy to announce the release of Falco 0.45.0 today! This release brings raw byte matching in rule conditions, new reload status and control endpoints, and fixes for package upgrades and container metadata collection. It also improves modern eBPF capture on preemptible kernels and adds sandbox rules for detecting suspicious GPU activity in containers.
