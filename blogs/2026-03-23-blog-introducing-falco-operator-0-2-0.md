Dear Falco Community, today we are excited to announce the release of Falco Operator 0.2.0 , the first production-ready release of the Kubernetes operator for Falco ! Since the technical preview announced with Falco 0.41.0 , we have been working hard to make the operator robust, extensible, and ready for real-world environments. This release brings a redesigned API, a new Component controller for managing the Falco ecosystem, new artifact management capabilities, enhanced observability, and a significantly improved operational model, all grounded in Kubernetes-native patterns.
