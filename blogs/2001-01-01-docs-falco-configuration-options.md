Falco's configuration file is a YAML file containing a collection of key: value or key: [value list] pairs. Depending on your installation type the configuration file could be located in /etc/falco/falco.yaml or loaded as a configmap in Kubernetes deployments. The full list of configuration items is documented in the file itself that you can find in your Falco distribution or in the Falco repository .
